📘 SMS Verification API Documentation

This backend service provides user authentication with 2FA (Two Factor Authentication) using the Twilio SMS API. Below are the available API routes.

Base URL

http://localhost:8080

GET /api

Returns a welcome message.

Response:
{
  "msg": "You have successfully reached the sms verification endpoints"
}

POST /api/v2/auth/register

Registers a new user.

Request Body (JSON):
{
  "username": "johndoe",
  "name": "John Doe",
  "email": "john@example.com",
  "password": "securePassword"
}

Response:
{
  "msg": "User registered successfully",
  "user": { ... }
}

POST /api/v2/auth/login

Logs in a registered user after phone verification.

Request Body (JSON):
{
  "username": "johndoe",
  "password": "securePassword"
}

Response:
{
  "msg": "User login successfully",
  "user": { ... }
}

POST /api/v2/auth/2fa/code

Sends a verification code to the user's phone number using Twilio.

Request Body:
{
  "phone": "+254712345678"
}

Response:
{
  "msg": "Verification code sent successfully",
  "sid": "VE********************"
}

POST /api/v2/auth/2fa/verify

Verifies the code sent to the phone and marks the user as verified.

Request Body:
{
  "phone": "+254712345678",
  "code": "123456",
  "id": "generated_user_id"
}

Response:
{
  "msg": "Verification code verified successfully",
  "sid": "VE********************"
}

Any other URL

Returns a 404 page showing the incorrect URL and a reminder that Twilio SMS is used.

Note: All sensitive operations like SMS verification rely on the Twilio Verify API. Ensure TWILIO_VERIFY_SERVICE_SID TWILIO_ACCOUNT_SID TWILIO_AUTH_TOKEN is set in your environment variables.
